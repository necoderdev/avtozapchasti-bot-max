# Security policy

## Секреты

- Токены хранятся только в переменных окружения.
- `.env` и его варианты исключены из Git и Docker build context.
- При любом подозрении на публикацию токена его необходимо отозвать и выпустить
  заново. Простого удаления токена из файла или коммита недостаточно.
- Не публикуйте логи, содержащие персональные данные заявок.

## Персональные данные

Бот обрабатывает VIN, адрес и телефон. Они находятся только в памяти процесса и
удаляются после успешной передачи заявки, отмены или часа бездействия. Доступ к
логам и переменным окружения сервера должен быть только у администратора.

## Сообщение об уязвимости

Не создавайте публичный issue с токенами или данными клиентов. Отзовите затронутые
секреты и свяжитесь с владельцем репозитория приватным способом.
